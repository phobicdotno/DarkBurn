## The owner's own work, ported

The protocol, register, FIFO, safety and `.chf` knowledge in this crate comes from the owner's own
clean-room analysis project, **phobicMlaserLinux** (https://github.com/phobicdotno/phobicMlaserLinux), which is the
owner's work and a separate project of theirs. It was read (never modified) and ported to Rust.

| Source in phobicMlaserLinux | Used for |
|---|---|
| `docs/analysis/04-controller-protocol.md`, `src/nexcut/mcc/framing.py`, `crc.py` | Frame layout, function codes, CRC-16/MODBUS and byte orders, exception replies, the logged frames used as test vectors |
| `docs/analysis/11-static-findings.md`, `docs/analysis/11-static/A1..A9`, `src/nexcut/mcc/registers.py`, `commands.py` | Register blocks, status and alarm bit tables, command vector builders and their units, the allow and deny lists |
| `src/nexcut/mcc/fifo.py`, `11-static-findings.md` section 5 | FIFO item grammar (12-byte tick), frame packing rule, flow control |
| `src/nexcut/mcc/safety.py` | Arming state machine, alarm reactions, comm-loss watchdog, soft limits, deadman lease |
| `src/nexcut/mcc/simulator.py` | The behaviour of the card simulator and its fault injection |
| `docs/analysis/03-chf-format.md`, `src/nexcut/io/chf.py`, `src/nexcut/model/` | The `.chf` grammar, reader and writer, number formatting, version gates |
| `docs/analysis/02-layer-params.md` | The fibre and CO2 craft parameter model |
| `docs/analysis/99-gaps.md` | The list of facts that still need a capture on the real card |

The two golden `.chf` files in the tests (a 500-byte version 5 circle and a 718-byte version 4 polyline)
were generated by this crate and cross-checked byte for byte against the owner's Python writer, which
in turn reproduces the sizes and checksums recorded in the owner's analysis for the two vendor samples
they shaped. No vendor file was opened, run or copied for this crate.

## Not used

* Nothing from the vendor download or any vendor binary or file (`Gweike-M3-Ultra`, `Mlaser`,
  `MainApp.exe`, `NCModule.dll`, firmware images) was opened, run, decompiled or copied.
* No code from GPL, LGPL or AGPL projects.
